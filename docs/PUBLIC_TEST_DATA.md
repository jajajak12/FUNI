# Public test data

The Anvil/Hardhat private keys embedded in local fork-E2E helpers are the
documented public development accounts, used only against the local Anvil
endpoint. They are not production credentials and cannot authorize a
production wallet.

Protocol deployment addresses, pool IDs, and bytecode hashes are public
Robinhood Chain protocol data. They are retained only where a test verifies a
deployment or a local fork against that public protocol data.
